# NFTStudio

NFTStudio is a high-performance, real-time-processing engine for blockchain-based digital asset creation and management.

With NFTStudio, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/NFTStudio.git`
2. `cd NFTStudio`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
